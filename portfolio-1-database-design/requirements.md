Each student is required to create a private GitHub repository for the course. The
repository must contain practical evidence of work throughout the semester, including
where applicable:
I. SQL scripts
II. Database schemas
III. ER diagrams or database models
IV. NoSQL implementations
V. Query execution plans and performance results
VI. Screenshots, configuration files, and test results
VII. Technical documentation and README files
Important: Students are expected to commit to work progressively. Waiting until the
deadline to upload all files may reduce the evidence of continuous portfolio
development.
Suggested Repository Structure:
advanced-database-portfolio/
├── portfolio-1-database-design/
├── portfolio-2-query-optimisation/
├── portfolio-3-transactions-concurrency/
├── portfolio-4-nosql/
├── portfolio-5-distributed-cloud/
└── README.md
